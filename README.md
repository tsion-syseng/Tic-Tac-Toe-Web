# Tic Tac Toe 🎮

## Project Overview 📝
A **web-based Tic Tac Toe game** built with HTML, CSS, and JavaScript. Two players take turns placing ❌ and ⭕ on a 3x3 board. The game detects wins, draws, and keeps score automatically.  

Player ⭕ is always **Tsion**, adding a personal touch.

---

## Features ✨
- Two-player mode 🧑‍🤝‍🧑 (Player ⭕ = Tsion)  
- Win/draw detection  
- Emoji-based X and O marks ❌⭕  
- Dynamic scoreboard  
- Hover and click animations  
- Board resets for a new game 🔄
